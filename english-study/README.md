# Business English Daily

경제·비즈니스 표현을 매일 익히고, 간격 반복(spaced repetition)으로 복습하는 학습 기록.

## 하루 흐름 (Asia/Seoul)

| 요일 | 시간 | 내용 |
|------|------|------|
| 평일 (월~금) | 06:00 | **Morning Story** — 새 표현 5개 + 복습 표현 2~3개를 녹인 **1문단** 이야기 (`stories/YYYY-MM-DD.md`) + 알림 |
| 평일 (월~금) | 21:00 | **Evening Test** — 오늘 배운 표현 + 복습 대상 표현 테스트 (`tests/YYYY-MM-DD.md`) + 알림 |
| 주말 (토·일) | 21:00 | **Weekend Review** — 아침 스토리 없이, 밀린 복습 대상 표현 10문항 총복습 + 알림 |

테스트는 웹앱에서 풀고 제출하면 채점·복습 일정·레벨이 자동 갱신된다.

## 웹앱

**https://claude.ai/artifact/GXbcrnJ4twi21hXbpgCUBY** (claude.ai 로그인 필요, 비공개)

- **오늘 학습**: 날짜별 스토리(1문단), 새 표현·복습 표현, "학습 완료" 체크
- **테스트**: 빈칸·한→영·객관식은 자동 채점, 작문은 모범 답안을 보고 자가 채점 → 정오답과 정답 표시
- **단어장**: 표현별 암기 단계(0~5), 다음 복습일, 정답률
- **기록·레벨**: 학습 달력, 테스트 점수, 레벨 변경 이력

레벨(Lv.1~5)은 테스트 제출 시 자동 조정된다. 레벨 변경 후 2회 이상 응시했고 최근 3회 평균이
85% 이상이면 한 단계 올리고, 60% 미만이면 한 단계 내린다. 아침 스토리는 레벨에 따라
새 표현 수(3~6개)와 난이도를 정한다.

데이터는 웹앱 DB(`days`, `vocab`, `tests`, `meta/state`)가 기준이다. 소스는 `web/index.html`,
초기 데이터 생성은 `tools/build_seed.py`. `stories/`는 백업, `vocab.json`은 2026-10-09 기준 스냅샷이다.

## 간격 반복 규칙 (Leitner)

`vocab.json`의 각 표현은 `box` 값(0~5)을 가지며, 다음 복습일은 박스에 따라 정해진다.

| box | 다음 복습까지 |
|-----|---------------|
| 0 | 1일 (새 표현 / 틀린 표현) |
| 1 | 2일 |
| 2 | 4일 |
| 3 | 7일 |
| 4 | 15일 |
| 5 | 30일 (mastered) |

- 테스트에서 **맞히면** box +1 (최대 5), **틀리면** box 0으로 리셋.
- 아침 스토리는 `next_review`가 오늘 이전인 표현을 우선 2~4개 다시 등장시킨다 (가장 오래 밀린 것, box가 낮은 것 먼저).
- 테스트에 답하지 않은 날의 표현은 박스를 유지하고 다음 날 다시 복습 대상이 된다.

## 파일

- `vocab.json` — 전체 표현 목록과 복습 상태
- `stories/` — 날짜별 아침 스토리
- `tests/` — 날짜별 저녁 테스트와 채점 결과
